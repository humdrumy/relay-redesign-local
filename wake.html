Setup
  1. Create Relay Wake in Slack with the app manifest. Install in your Slack workspace; invite to #test.
  2. Set the Site secret SLACK_BOT_TOKEN and RELAY_PUBLIC_URL, then redeploy. Keep tokens out of messages.
  3. Configure dot’s Slack trigger for #test and connect the Relay plugin. Call relay_read_inbox, read the task or room, then call relay_ack_wake with the wake ID.
  4. Send a test notification. If delivered without a receipt, check dot’s trigger, Relay connection and run history.

Retries require an open page or a new Relay event. Timeouts may duplicate delivery; acknowledgments are idempotent. Retention: 100 completed or failed deliveries.
